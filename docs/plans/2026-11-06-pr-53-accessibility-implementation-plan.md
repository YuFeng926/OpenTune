## 1. 产品目标

在“选项 → 编辑”提供设置：

> 无障碍模式：为视障用户准备的读屏播报和编辑等功能

无障碍模式启用后，提供一条独立的键盘与读屏交互流程，覆盖 OpenDyne PianoRoll、音符导航/编辑、属性播报、键盘 EQ、参数与相关对话框操作，以及按产品设置触发的音符试听。关闭时保留既有明眼用户的视觉、鼠标、键盘和声音行为。

独立的是交互路由、焦点、键盘选择/编辑反馈、读屏播报与试听策略。音符、时间网格、revision、内容提交、Undo/Redo 和项目持久化仍使用现有领域状态与事务入口，不建立第二份内容模型或 Undo 栈。

Standalone 与 VST3 使用同一模式设置和 PianoRoll 交互语义。REAPER 光标读取作为 VST3 宿主扩展；键盘音符浏览以宿主光标和当前音符选择状态确定起始位置。

## 2. 无障碍模式行为

- 偏好项存入现有应用偏好系统，在 Standalone 与 VST3 编辑器中读取同一设置。
- 新安装默认关闭，以保留普通用户现有的键盘和听觉交互。设置项及其描述本身始终可被读屏访问。
- 开启后启用无障碍键盘路由、音符焦点/选择反馈、读屏播报和已批准的键盘试听行为。
- 关闭后不消费新增的音符编辑快捷键、不自动播报音符、不自动试听；普通鼠标编辑流程保持原样。
- 模式内使用单独的键盘编辑状态和焦点策略。键盘事件只在 PianoRoll 获得相应焦点时处理；文本输入、菜单、对话框和 VST3 宿主快捷键保留各自语义。
- UIA 节点为 NVDA 对象导航提供稳定音符信息。模式开关不使设置项本身失去可访问性。
- 试听开关及其触发策略属于无障碍模式的声音行为；导航试听、编辑后试听和正常宿主播放互不混用。

## 3. 已确认的时间与数值契约

以下数值和交互语义经用户确认，实施不得自行改步长、精度或边界。

### 3.1 时间编辑与宿主时间

| 操作 | 固定规则 |
|---|---|
| 键盘音符边界调整 | `Ctrl+Left/Right` 调整终点；`Ctrl+Shift+Left/Right` 调整起点；每次 `0.01 s`。使用现有 resize planner、编辑范围、最小时长和相邻音符约束。 |
| 最短音符/分割片段 | `0.02 s`。 |
| 键盘合并 | 相邻容差 `0.02 s`；合并边界取两音符边界中点；沿用现有容差 epsilon。 |
| 键盘分割 | 默认按音符中点；显著 F0 跳变分析取切点前后各 4 帧，跳变阈值 `0.5 MIDI`；切点经 F0 timeline 的 `timeAtFrame()` 映射。最短片段仍为 `0.02 s`。 |
| REAPER 光标 | 工程时间经现有 `PianoRollTimeMap` 映射到源时间；暂停光标移动比较容差 `1e-6 s`。停止状态的粘贴按宿主编辑光标定位。 |
| 播报时间 | 音符位置、时长转换为工程时间后以 2 位小数播报；只格式化播报文本，不量化音符数据。 |

### 3.2 音符试听的样本表示

- `Note.startTime` 与 `Note.getDuration()` 是试听范围的时间来源；在音频片段边界转换为样本索引/样本数。
- 起点和样本长度用 `llround(seconds * sampleRate)` 取最近样本；半值按 `llround` 规则远离零。
- 单次键盘音符试听上限 `4.0 s`。
- 淡入/淡出时长 `0.005 s`，按 `static_cast<int>(seconds * sampleRate)` 转为样本数并向零截断。
- 混音重采样步长为 `clip.sampleRate / outputSampleRate`；源浮点位置的整数索引向零截断，余数用于线性插值。
- 源时间只从样本位置按 `sourceSeconds = sampleIndex / sampleRate` 计算以评估片段内音量包络；不得据此反推或改写项目绝对时间。
- canonical render 叠加的采样率差阈值为 `< 1 Hz`。
- 声道平均增益为 `1.0f / sourceChannels`；dB 到线性增益沿用 `0.11512925465f` 常数。

### 3.3 Timer 语义

| Timer 行为 | 处理规则 |
|---|---|
| AccessibleKnob 提交防抖 | 保留 `400 ms`；连续键盘调整合并为一次提交。计时器到期即停止并提交，不重复提交。 |
| 编辑结果试听 | 删除 `150 ms` 周期检查 `render settled` 的轮询及 2–35 tick 计数策略。由渲染完成/失败/取消终态事件触发试听或播报。 |
| 渲染完成播报 | 保留 `1000 ms` 最短渲染时长门槛；从渲染完成事件读取开始时间并决定是否播报，不新增周期 timer。 |

### 3.4 非时间数值

这些规则只影响参数编辑和语音格式化，不属于绝对时间契约。

- `NoteSpeech`：`lround(midi * 100)` 得总音分；`(totalCents + 50) / 100` 取最近半音，正向半音中点归高音；音分偏差为 `totalCents - nearest * 100`。
- PianoRoll 音高：微调 `0.01 MIDI`（1 cent）；半音移动使用 floor/ceil 跳至相邻半音；Chromatic 路径使用 `round` 到整数 MIDI；调式路径量化至当前音阶。
- 音量键步长：普通 `1 dB`、细调 `0.1 dB`。调制/漂移：普通 `0.05`、细调 `0.01`；调制限制 `[0,1]`。
- EQ 频率：普通键按半音倍率 `value * pow(2, direction / 12)` 并 `round` 到整数 Hz；Page 按八度；Alt 每次 `1 Hz`。Gain 步长 `3 / 0.5 / 0.1 dB`；Q 步长 `1 / 0.1 / 0.01`。
- EQ 播报：频率取整数 Hz；Gain 取 `0.1 dB`，绝对值小于 `0.05 dB` 显示为 0；Q 保留 2 位小数。
- 音量播报取 `0.1 dB`，绝对值小于 `0.05 dB` 显示为 0；调制/漂移播报为无小数百分比。
- AccessibleKnob 的既有 PR 步长保留：偏好设置缩放 `0.05/0.01/0.2`、滚动速度 `5/1/30`、调音基准 `1/1/10 Hz`、背景亮度 `0.05/0.01/0.25`；插件 Retune Speed 与 Vibrato Depth `1/0.1/10`、Vibrato Rate `0.1/0.01/1`、Note Split `5/1/20`。
- Pitch Shift：半音键步长 `1`、Page 步长 `12`；音分键步长 `1`、Page 步长 `10`；显示取整到整数。

## 4. 线程与音频边界

- ARA DocumentController、ARA 模型、F0 completion 和相关析构继续遵守消息线程单线程所有权契约。
- 消息线程准备试听请求及不可变音频数据；可复用现有 worker 渲染、原子发布模式。
- 音频线程只读取已发布的稳定音频片段并按样本混入输出；不得访问 DocumentController，不得获取 `SpinLock`，不得忙等。
- 试听源的设置、替换、取消与释放由所属消息线程完成。processor/editor 析构不得从未确认的线程直接调用 DocumentController 释放接口。
- 键盘编辑提交使用现有 Processor/ContentEditCommands、revision 校验、缓存失效和 Undo/Redo。无障碍交互层拥有独立路由与反馈，不复制领域状态。
- 不修改 F0 后端渲染算法、离线渲染、项目时间数据或正常播放/导出结果。键盘试听是编辑器旁路预览，不写入项目内容。

## 7. 验收

- Windows NVDA 可在 PianoRoll 对象导航中逐项浏览音符，并读出音高、位置、时长和选中状态。
- 无障碍模式下可用键盘浏览、选择和编辑音符；设置文案、键位和实际行为一致。
- 时间编辑与读屏数值严格遵循第 3 节；不在后端渲染中引入 PR 的交互换算逻辑。
- 编辑后试听使用已完成渲染数据；无 150 ms 周期轮询，无音频线程锁/忙等/ARA Controller 访问。
- F0 completion 与 ARA DocumentController 生命周期继续只在消息线程完成。
- Standalone 和 REAPER VST3/ARA 均通过 Windows NVDA 手工工作流；验证停止、播放、暂停光标、音符编辑、试听、undo/redo、关闭编辑器和关闭项目。

## 10. 偏移即停工

出现以下情况时停止当前阶段并向用户汇报：

1. 需要改变第 3 节用户确认的时间或数值规则。
2. 试听需要访问 ARA DocumentController、锁、忙等或改变后端渲染。
3. 实施需要新增本计划未列出的时间轮询、持久化格式或 API 协议。
4. 无障碍模式无法隔离新增键盘、播报或自动试听行为。
5. 必须把 API 分支既有 Control API 历史整体带入 standalone。
