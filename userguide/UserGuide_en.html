1. Introduction

OpenTune is an open-source AI pitch correction application built on a neural vocoder. It uses the PC-NSF-HiFiGAN vocoder to regenerate vocals while preserving the original formants, so even extreme pitch adjustments stay natural and solid.

OpenTune offers two working modes: Standalone and VST3/ARA (DAW plugin). Use it as an independent multi-track editor or embed it in a DAW for collaborative editing. The macOS version also provides an AU component.

Two Correction Methods

MethodWhen to UseSound and Speed
Lightweight ProcessingSmall corrections, up to about 75 centsFast processing that keeps the detail and texture of the original recording
AI ResynthesisLarge changes: hand drawing, anchors, whole-clip pitch shift, and corrections beyond about 75 centsRegenerates the vocal with consistent quality and a short render wait

With Hybrid Mode enabled in Preferences → Audio, the software picks between these two methods based on correction size. With it off, all corrections use AI resynthesis.

Model Location
AI models live in the system's public program data directory (C:\ProgramData\OpenTune\Models on Windows), and the standalone app and the plugin share the same model files. Moving or deleting this directory stops pitch correction from working.

3.3 Launching the App

Double-click OpenTune.exe to start the standalone app; AI models initialize automatically on first launch. For the plugin, place OpenTune.vst3 in your DAW's VST3 scan folder, or select the plugin component during installation so the installer registers it.

3.4 First Launch: Onboarding and Demo Project

The first launch opens Onboarding automatically. The guide starts by confirming your editing workflow:

  • OpenTune — edit notes; ideal for refining note by note.
  • OpenDyne — edit waveform blobs; ideal for shaping the performance as a whole.
  • Not now — skip the choice and go straight to the tour.

The guide then points in turn to the File, Edit, and View menus, the audio entry, the track view, the piano roll, the editing tools, the Retune Speed and vibrato parameters, AUTO / SNAP, the scale, the overview strip, the transport buttons, and Help and options. The guide card shows the current step (for example “4 / 12”), with Previous and Next buttons and Exit guide at any time. Steps adapt to the running environment: Standalone, ARA plugin, and capture mode each show different tips.

When the guide ends and the project is still empty, the app loads the Demo project automatically and shows three tips in order:

  1. Demo project — the demo song is loaded on the track; double-click the audio clip to edit its pitch in the piano roll.
  2. Rendering audio — loading a project, editing pitch, or transposing starts rendering; during rendering you hear the original pitch.
  3. Editing tools — the tools on the right correct pitch; hover over a tool to see its name and usage.

Each step offers Skip Tour. The demo project appears automatically only on the first launch and never overwrites an existing project.

Viewing the Guide Again
Reopen the guide from the File menu through Help → Onboarding..., or click Replay onboarding on the Preferences → Audio page.

5. Quick Start

1

Import Audio

Drag audio files into the window, or choose File → Import Audio. Supported formats include WAV, AIFF, FLAC, OGG, and MP3.

2

Wait for Pitch Analysis

After import, the app analyzes the audio and extracts the original pitch, shown as a pitch curve in the piano roll. The interface shows “Processing audio” during analysis.

3

Confirm the Scale

The app detects the scale automatically. You can also pick the root (C–B) and scale type (Major, Minor, Chromatic, and five more — 8 in total) in the top toolbar.

4

Edit Pitch

Use auto correction to snap to the scale in one click, or refine note by note with Line Anchor, Hand Draw, and Draw Note. The correction appears as a second curve above the original pitch.

5

Adjust Parameters

Adjust Retune Speed, Vibrato Depth, Vibrato Rate, and more in the parameter panel. With notes selected, changes apply only to those notes.

6

Audition and Export

Press Space to play. Once rendering completes you hear the corrected audio; export it through File → Export Audio.

What You Hear During Rendering

After a pitch edit, the app resynthesizes audio in the background and shows Rendering (done/total) in the top right. Playback uses the original pitch until rendering ends, then switches to the corrected audio automatically.

6. Core Features

6.1 Audio Import

  • Supported formats: WAV, AIFF, FLAC, OGG, and MP3, plus WMA on Windows.
  • Mono and stereo audio are supported; files with more than two channels cannot be imported.
  • Import by drag and drop, or through File → Import Audio; when you select several files at once, the app asks how to import them: Import Sequentially To Current Track or Import To Separate Tracks.
  • Multi-track support: up to 12 tracks, each holding multiple clips. When the import count exceeds the free tracks, the app notifies you and imports only what fits.
  • Import keeps the original sample rate, and editing and resynthesis use a unified 44.1 kHz working copy.
  • A progress display shows during import, and only one import task runs at a time.

6.2 Pitch Analysis

  • After import, the original pitch is extracted automatically and shown as a pitch curve whose color you can customize in Preferences.
  • The FCPE deep-learning model works especially well on vocals and monophonic melodies.
  • Each piece of audio is analyzed only once; re-importing it or reopening the project reuses the result.
  • If analysis fails, the interface reports it and notes that re-importing the audio regenerates the pitch.

6.3 Scale Detection and Selection

The app detects the scale automatically, and you can set it manually. A manual scale makes auto correction target the notes of that scale across the whole clip. The 8 supported scales:

ScaleAbbrev.Description

MinorMin.Natural minor scale
ChromaticChr.All 12 semitones are available; auto correction snaps to the nearest semitone
Harmonic MinorH.Min.Minor scale with a raised 7th degree
DorianDor.Common in jazz and blues

6.4 Pitch Correction and Resynthesis

  • After a pitch edit, the app chooses lightweight processing or AI resynthesis based on the size of the change, then produces playable audio.
  • Small corrections (up to about 75 cents) use lightweight processing when Hybrid Mode is on, which is fast and keeps the original detail.
  • Hand drawing, anchors, whole-clip pitch shifts, and corrections beyond about 75 cents always use AI resynthesis, preserving formants so wide transpositions stay clean.
  • The output sample rate is 44.1 kHz, with natural, clear sound.
  • Rendering runs in segments, so long audio can be edited while it renders; the top-right badge shows progress.

6.5 Multi-Track Management

  • Up to 12 independent tracks, each supporting multiple clips.
  • Track controls: mute, solo, and a volume knob (0–4.0×) with a real-time level ring around it.
  • Track context menu: Add Track, Duplicate Track, Track Color (Custom Color / Random Color), Delete Track.
  • Clip operations: move, trim left and right, adjust fades, adjust gain, split, merge, duplicate in place, and delete.
  • Double-click a clip to open it in the piano roll for editing.

6.6 Undo and Redo

  • Stores up to 500 steps of operation history.
  • Covers every editing operation: note drawing, pitch edits, parameter changes, clip operations, track operations, and project changes.
  • Shortcuts: Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo.

7. Editing Tools

Switch editing tools from the tool area in the right parameter panel or with keyboard shortcuts. Hover over a tool button to see its name, usage, and shortcut. Shortcuts in parentheses in this chapter are Windows defaults; macOS defaults are in Chapter 11.

7.1 Tools in the OpenTune Scheme

Auto Correction AUTO (Shortcut: 6)

Snaps pitch to the nearest note of the current scale. With notes, a selection, or a pitch range selected it processes only that part; with nothing selected it processes the whole clip. One pass is enough to hear the result, and running it again on already corrected material changes nothing.

Select Tool (Shortcut: 3)

Select notes or time regions; after selecting you can move, delete, or adjust parameters.

Operations: click to select, drag to marquee-select, Shift+click to multi-select, Delete to remove; drag a note edge to resize it and drag its middle to change pitch or position.

Draw Note (Shortcut: 2)

Draw note blocks by hand: drag in the piano roll to create a note with a chosen pitch and duration.

Feature: each note gets its own Retune Speed, Vibrato Depth, and Vibrato Rate.

Line Anchor (Shortcut: 4)

Place key anchors on the pitch curve; the app connects them with straight transitions, which suits precise control of glides and pitch bends. Anchor edits use AI resynthesis.

Hand Draw (Shortcut: 5)

Draw the pitch curve directly for complete control of the pitch contour; suits vibrato, glides, and bends. Hand-drawn regions use AI resynthesis.

Eraser

Brush erase: hold the left button and drag to remove notes and pitch correction inside the round brush in one stroke, recorded as a single undo step.

Operations: pick the eraser in the parameter panel or the right-click toolbar, then hold the left button and drag; no default shortcut.

EQ (Shortcut: E)

Adds frequency equalization to individual notes. Switch to the EQ tool (or press E) and click a note to open its EQ editor, where you add, bypass, and remove bands on the spectrum; hold and drag to marquee-select several notes.

Operations: up to 10 bands per note; filter types are low cut, low shelf, peak, high shelf, and high cut; peak bands cover 500 Hz–12 kHz and the other types 20 Hz–20 kHz; gain range is ±12 dB and Q range is 0.25–9. In the editor you can collapse to preview, bypass temporarily, or remove the whole chain. It asks for confirmation before removal, and you can choose Don't show again.

Time Tool (Shortcut: T, Experimental)

Drag time handles to adjust the audio's output timing for time-stretch effects. The tool appears only after you turn on Enable Experimental Features in Preferences → Audio, and it is available in the Standalone app only.

Operations: entering the Time Tool hides piano keys and pitch curves and shows draggable time handles. Drag a handle to change timing; hold Alt while dragging to lift the minimum spacing limit; Shift+click to multi-select handles; double-click empty space to insert a handle; Delete removes selected handles; click empty space to reposition the playhead.

Limits: the first and last endpoints are fixed and total duration stays the same; endpoints cannot be selected or deleted; handles keep a minimum spacing and stay in place when an insert or drag breaks it. Each adjustment requires resynthesis, and the new timing plays after rendering finishes.

In the OpenDyne scheme the same button in the parameter panel reads SNAP: press it to snap selected notes in one click, or all notes when nothing is selected. The Pitch Grid decides how dragging snaps: No Snap, Chromatic, or Key Scale.

7.3 Piano Key Audition

Click a piano key on the left of the piano roll to hear that pitch as a piano note; hold and drag to glide across keys, and release to stop. The pressed key is highlighted.

7.4 Note Drag Audition

With Preview transposition while dragging notes enabled in Preferences → Editing, dragging a note to a new pitch plays the target pitch immediately, which is a fast way to find a note. The same option controls audition after keyboard edits. With it off, dragging only changes the display and makes no sound.

8. Parameter Reference

8.1 Pitch Correction Parameters

Retune Speed
Range: 0% – 100% | Default: 15%

Controls the speed and strength of pitch correction. Higher values correct faster and more precisely; lower values keep more of the original pitch movement.

  • Low (0–30%): preserves natural vibrato, ideal for a realistic feel
  • Medium (30–70%): balances precision and naturalness
  • High (70–100%): precise correction with a clear Auto-Tune effect; at 100% note boundaries switch instantly with no transition

Per-note: select notes before adjusting to affect only those notes.

Vibrato Depth
Range: 0% – 100% | Default: 0%

Sets the amplitude of artificial vibrato added to notes. 0 adds none and 100% is the maximum depth. Supports per-note settings.

Vibrato Rate
Range: 3 – 12 Hz | Default: 7.5 Hz

Controls the oscillation frequency of artificial vibrato. Natural vocal vibrato usually falls between 5 and 8 Hz. Supports per-note settings.

Note Split
Range: 0 – 200 cents | Default: 80 cents

Controls sensitivity when notes are divided automatically: lower values split a continuous performance into more independent notes. Releasing the mouse after an adjustment re-divides the notes as one undo step.

Common Knob Controls

Drag a knob to change the value and use the wheel to fine-tune. When a knob has focus: arrow keys nudge, holding Alt uses fine steps, PageUp/PageDown make large changes, Home sets the maximum and End the minimum, Backspace restores the default, and Enter types a value directly (Enter confirms, Esc cancels).

8.2 Pitch Shift

Pitch Shift (parameter panel button)
Range: ±24 semitones, ±99 cents

Shifts the current clip up or down as a whole. Click the button to open a dialog and set semitones and cents separately; confirming resynthesizes the whole clip at the new pitch. The button shows the current shift so you can check it at any time. Pitch Shift always uses AI resynthesis.

8.3 Pitch Grid (OpenDyne)

Pitch Grid
Options: No Snap / Chromatic / Key Scale | Default: Key Scale

Sets how pitch dragging snaps in the OpenDyne scheme. No Snap drags freely in cents; Chromatic snaps to the nearest semitone; Key Scale snaps to the notes of the current root and scale.

8.4 Track and Transport Parameters

Track Volume
Range: 0 – 4.0× | Default: 1.0

The track volume knob supports gain above 1.0, with a real-time level ring around it.

Tempo and Time Signature
Tempo range: 1 – 999 BPM | Default: 120 BPM, 4/4

Controls project tempo, timeline grid, and beat display. Click the number to type a tempo; click the time signature digits on the right to choose beats per bar (1–64) and the beat value (1, 2, 4, 8, 16, 32, 64).

Tap Tempo

Tap the Tap Tempo button repeatedly; the app averages the intervals of the latest taps and fills in the tempo, rounded to one decimal. A gap of more than 2 seconds restarts the calculation.

Time Display and Scroll Mode

The ruler switches between time (minutes and seconds) and bars/beats; Scroll Mode switches between Cont and Page.

9. Editing Schemes

OpenTune provides two editing schemes, switched under Preferences → Editing → Audio Editing Scheme; the interface changes immediately.

9.1 OpenTune Editing (Default)

  • Works note by note: note blocks, the original pitch curve, and the correction curve are visible together.
  • Tools: Auto Correction, Select, Draw Note, Line Anchor, Hand Draw, Eraser, EQ, and the Time Tool.
  • Dragging notes snaps according to Move Snap: Follow Global Scale or Snap to Semitones.
  • Default wheel mapping: wheel scrolls vertically / Shift + wheel zooms vertically / Ctrl + wheel zooms horizontally / Alt + wheel scrolls horizontally.

9.2 OpenDyne Editing

  • Works in waveform blobs, suited to whole-performance shaping and a Melodyne-style workflow.
  • Tools: Select, Pitch, Modulation, Drift, Volume Envelope, and Scissors, plus the Time Tool and EQ.
  • The right-click toolbar is an icon strip; the Pitch tool has a dropdown arrow that opens the Modulation and Drift sub-tools. The auto correction button in the parameter panel reads SNAP and snaps in one click.
  • Offers Pitch Grid selection and one-click snapping.
  • Ctrl (Windows) or Cmd (macOS) + Alt double-click a note to zoom to it; the same action on empty space restores the previous zoom.
View Operations Common to Both Schemes

Double-click the vertical scrollbar to fit all notes; the overview strip at the bottom browses the whole clip while keeping the current zoom.

Wheel Mappings Are Customizable

Change wheel and key mappings for both schemes in Preferences → Shortcuts under OpenTune Mode and OpenDyne Mode; defaults are listed above. Changes apply immediately.

12. Accessibility Mode and Keyboard Editing

With Accessibility mode enabled in Preferences → Editing, the interface supports screen reader announcements and notes can be edited entirely from the keyboard. With it off, the arrow keys only perform basic pitch moves and note switching.

12.1 Screen Reader Announcements

  • Control names and current values: knobs, dropdowns, checkboxes, and tabs.
  • Operation results: the item undone or redone, the number of notes removed, split and merge results, and whether auto correction was applied.
  • Note information: note name, pitch change, start and end time, modulation, drift, and volume.
  • Playback position and current state: the position when paused, and an explanation when the position cannot be obtained during playback.
  • Render status and render progress.

12.2 Keyboard Note Editing

14. GPU Acceleration

OpenTune accelerates pitch analysis and vocoder inference on the GPU, significantly speeding up processing.

14.1 Supported Platforms

  • Windows: NVIDIA / AMD / Intel GPUs through DirectML
  • macOS: system graphics acceleration through CoreML
  • When no GPU is available or the GPU is unsupported, processing switches to the CPU with no loss of features

14.2 Configuration

In Preferences → Audio → Rendering Priority, choose:

  • GPU First (default): uses GPU acceleration first
  • CPU First: uses the CPU entirely, suitable when GPU drivers are unstable
What Happens After a Switch

Switching Rendering Priority reloads the processing engine; switching Hybrid Mode resynthesizes existing clips the new way with progress in the top-right badge; switching Pitch Detection Model affects later pitch analysis and leaves analyzed clips as they are.

15. VST3/ARA Plugin Mode

The OpenTune plugin loads into a DAW in VST3 format and supports non-destructive editing through the ARA2 extension. The macOS version also provides an AU component.

15.1 How It Works

  • Once loaded in a compatible host (such as Studio One, Cubase, REAPER, or Logic Pro), all pitch work happens inside the plugin window.
  • ARA hosts supply audio data directly, with no file import or export; edits show up in host timeline playback in real time.
  • Supports host transport sync (play/stop/locate) and tempo following.
  • Reading and editing apply only to the currently selected region, and regions in a multi-region project stay independent.
  • When the input audio changes, the original pitch refreshes automatically.
  • Playback uses the original pitch until rendering completes, then switches to the corrected audio automatically.

15.2 Reading Audio

All audio reading in the plugin goes through the Read Audio button (red round icon) in the top toolbar, and the two host types behave differently:

Host TypeActionResult
ARASelect the audio event in the host and click Read Audio onceReads the selected region and starts analysis; the piano roll then shows the pitch curve. If it was already read, the app reports “Audio already read”.
No ARAClick Read Audio to start capture, start host playback, then click again when you reach the position you needThe button stays lit during capture; when it ends, the app analyzes the audio automatically and makes it editable. Each capture creates a new recording region and leaves existing regions unchanged; overlaps caused by locating back and forth during capture merge automatically, so no sound is duplicated.

15.3 External Edit

The “External Edit” button in the plugin hands the current pitch curve to the OpenTune standalone app for detailed work:

  1. Click External Edit; the standalone app starts and opens the editor for that audio.
  2. Edit the pitch in the standalone app and click Save and Return.
  3. The plugin reads the result back automatically and announces “External edit applied”.

Clicking before audio is read prompts you to read audio first; if the returned curve file is corrupt, the session stays open so you can fix it in the standalone app and save again.

16. Audio Export

16.1 Export Format

  • Format: WAV
  • Sample Rate: 44.1 kHz
  • Bit Depth: 32-bit Float
  • Channels: mono for clips and tracks, stereo for the bus mix

16.2 Export Range

OptionDescription
Export Selected ClipExports only the selected audio clip, with the pitch correction applied to it
Export TrackExports the mixed result of all clips on the chosen track
Export Bus (Master Mix)Exports the final mix of all tracks

16.3 Export Workflow

  1. Choose the menu File → Export Audio and pick the export range.
  2. Choose the save location and file name.
  3. If the target file exists, the app asks whether to overwrite it.
  4. Wait for background rendering to finish; the app then reports the full path of the exported file, and reports the reason if it fails.
Let Rendering Finish Before Exporting

Export waits for all clips to become ready and then writes the file; while rendering is in progress the export queues, so seeing the Rendering badge beforehand is normal. Only one export task runs at a time.

17. FAQ

Q1: No pitch curve after importing audio?

A: Make sure C:\ProgramData\OpenTune\Models\fcpe.onnx exists and is intact. The audio needs a clear vocal melody; pure accompaniment or percussion yields no usable pitch data. If analysis fails, the interface reports it, and re-importing the audio runs the analysis again.

Q2: GPU acceleration is not working?

A: Check each of the following:

  • The program directory contains DirectML.dll and a complete D3D12 folder
  • The GPU driver is up to date
  • Preferences → Audio → Rendering Priority is GPU First
  • The log directory shows that GPU acceleration loaded

Q3: Playback during rendering still uses the original pitch?

A: This is the expected state. Editing pitch, transposing, or opening a project requires resynthesis; until rendering completes, playback uses the original pitch and the top-right badge shows Rendering (done/total). Once the badge disappears, playback uses the corrected audio.

Q4: The Time Tool is missing?

A: The Time Tool is experimental: select Enable Experimental Features (Time Stretch Tool) in Preferences → Audio and the Time Tool button appears in the tool area. The plugin does not include this feature.

Q5: Corrected audio sounds wrong?

A: Typical causes: corrupt model files (a reinstall restores them), Retune Speed set too high (lower it below 30%), and poor source recordings. Lower Retune Speed and fewer edits bring the sound closer to the original performance.

Q6: How do I get a natural correction?

  • Use a low Retune Speed (10%–30%)
  • Keep the original vibrato and add no artificial vibrato
  • Use the Line Anchor tool to fine-tune key moments and change only what needs changing
  • Turn on Hybrid Mode so small corrections keep the original texture

Q7: The plugin does not load in my DAW?

A: Make sure the OpenTune.vst3 folder is complete (it contains the Contents\x86_64-win\ subdirectory) and the model files are in C:\ProgramData\OpenTune\Models. Rescan the host's VST3 folder after installation; using ARA requires an ARA2-capable host version.

Q8: Read Audio does nothing in the plugin?

A: In an ARA host, select an audio event in the host first; with nothing selected or the event not yet ready, the app asks you to select again. In a host without ARA, click Read Audio, start host playback, and click again to stop capture when playback ends.

Q9: How do I change the interface language?

A: Preferences → Theme → Interface Language; the interface switches as soon as you pick a language. Chinese, English, Japanese, Russian, and Spanish are supported.

Q10: What do I do when rendering or pitch analysis fails?

A: The app shows a diagnostic message (for example “Render failed; dry audio may be used. Reason: …”) with the log file path and the latest log content, ready to copy into a report. Log folders: Windows %APPDATA%\OpenTune\Logs, macOS ~/Library/OpenTune/Logs/.

Q11: A saved project has no audio on another computer?

A: Saving a project creates a matching “ProjectName_Media” folder next to the project file and copies the audio it uses. When moving the project, copy the .otproj file together with the matching _Media folder.

Q12: Shortcuts do nothing?

A: First make sure focus is in the piano roll or the arrange view; inside the plugin, play, pause, and stop belong to the host and those three shortcuts do not respond. If a key conflicts with the system or another app, use the wheel or a mouse side button in Preferences → Shortcuts.
